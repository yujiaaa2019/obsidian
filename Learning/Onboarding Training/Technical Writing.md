Don't write about **why** 
Write about the **how to use** the software you build to solve user problem

- Site 
	- info architecture 
	- categories 
- Page 
	- flow
- Line 
	- grammar 

**Consistency builds trust** 
- visually 
	- title, heading, sentence casting... 

## Tips
1. use Bullet lists for lots of small ideas 
2. use number lists for processes 
3. short paragraphs are better 
4. pay attention to Site, Page, Line levels 
5. Do one thing at a time on a page 
	1. separate into tutorial, concept, reference, or procedural 
	2. Make clear navigation 
6. Avoid Jargons 
	1. define the technical terms
