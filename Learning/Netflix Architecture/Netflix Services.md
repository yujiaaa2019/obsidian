## Content Knowledge Graph 
Hitch data space: 
- **Source** data from various external and internal sources, aligning common attributes to standard namespaces
- **Match** source entities together, creating groups across sources that all look like the same thing
- **Curate** attributes to publish a consistent view across data sources, and thus simplifying downstream use of this data.
